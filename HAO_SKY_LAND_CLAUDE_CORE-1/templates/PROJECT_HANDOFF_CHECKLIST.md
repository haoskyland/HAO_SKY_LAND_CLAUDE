# CHECKLIST BÀN GIAO DỰ ÁN

- [ ] Mục tiêu và trạng thái dự án được ghi rõ.
- [ ] README/hướng dẫn chạy được cập nhật.
- [ ] File nguồn, media và tài nguyên cần thiết đã xác định.
- [ ] Không còn đường dẫn cục bộ không được ghi chú.
- [ ] Không có API key, mật khẩu, OTP hoặc dữ liệu khách hàng trong repo.
- [ ] File cấu hình mẫu dùng placeholder.
- [ ] Test/lint/build phù hợp đã chạy hoặc ghi rõ lý do không chạy.
- [ ] Kết quả đã được mở/kiểm tra thực tế nếu có đầu ra thị giác.
- [ ] Thay đổi và cách rollback được mô tả.
- [ ] Backup được xác nhận thực tế nếu tuyên bố đã backup.
- [ ] Chưa tự commit/push/deploy/gửi tin/công khai nếu chưa được yêu cầu.
